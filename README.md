# ReAnimator - Merged (Animation + Skitch)

Custom animations and player skitching combined.

## Features
- Custom Animations (poseanim) - Play custom .rska animations
- Player Skitching - Hold V (rebindable) or LB+RB near another player to skitch by the hip

## Installation
1. Install ReSkate
2. Replace ReSkate.dll from dist/
3. Launch through ReSkate launcher

## Usage
Skitch hotkey: Settings → Controls (below Forward/Up Boost). Default V. LB+RB also available.
Animations: poseanim test|record|play|off|save <path>|mask auto/full/legs|trace 0/1|<file>.rska
