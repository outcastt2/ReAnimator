# ReAnimator - Animation

Custom animation playback for your skater. No skitching.

## Features
- poseanim commands for playing, recording, and loading .rska animations

## Installation
1. Install ReSkate
2. Replace ReSkate.dll from dist/
3. Launch through ReSkate launcher

## Usage
poseanim test|record|play|off|save <path>|mask auto/full/legs|trace 0/1|<file>.rska
