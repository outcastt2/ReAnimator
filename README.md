# ReAnimator - Skitch

Player skitching (hip towing) with rebindable hotkey. No animations, ragdoll drag, or unlocks.

## Features
- Player Skitching - Hold V (rebindable) or LB+RB near another player to skitch by the hip
- Skitch hotkey configurable in Settings → Controls

## Installation
1. Install ReSkate
2. Replace ReSkate.dll from dist/
3. Launch through ReSkate launcher

## Usage
Rebind hotkey in Settings → Controls (below Forward/Up Boost). Default V. LB+RB also available.
